Publish free with GitHub Pages:
1. Create a new PUBLIC repository on GitHub (for example: sree-thirumala-tours).
2. Upload index.html and the complete assets folder (keep the folder structure).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish; the website URL will appear in Settings > Pages.

This is a static website. Booking buttons open WhatsApp or the phone dialler; they do not process payments or store bookings.
